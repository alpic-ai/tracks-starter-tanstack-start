# TanStack Start starter

A minimal TanStack Start app in React and TypeScript with file-based routing and Tailwind CSS, no database.

- `src/routes/index.tsx`: the home page
- `src/routes/__root.tsx`: the root layout
- `src/components/`: the header and footer
- `src/styles.css`: global styles and Tailwind CSS
- `vite.config.ts`: Vite configuration

## Run

```sh
npm install
npm run dev
```

Then open http://localhost:3000.
